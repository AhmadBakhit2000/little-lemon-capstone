# Little Lemon Table Booking Web Application

This is the Capstone Project for the Meta Front-End Developer Professional Certificate. It is a responsive React web application for the Little Lemon restaurant that allows users to reserve a table online with full form validation and accessibility support.

## Features
- Responsive UI/UX following Little Lemon design guidelines
- Semantic HTML5 structure and ARIA accessibility attributes
- Interactive table reservation form with real-time validation and edge-case handling
- Unit tests built with Jest and React Testing Library

## Setup & Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd little-lemon-capstone
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Run unit tests:
   ```bash
   npm test
   ```
